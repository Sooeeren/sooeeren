## Hi, I'm Soeren

I build web apps, run my own infrastructure and design roller coasters in my spare time. I like projects where I can take an idea from a sketch to something running on my own hardware.

### 🔭 What I'm into

- **Web development** with Vue.js, TypeScript and Tailwind CSS
- **Self-hosting**: Docker-based homelab setups
- **3D printing** and tinkering with hardware
- **UI design** in Figma

### 🎢 Roller coasters
